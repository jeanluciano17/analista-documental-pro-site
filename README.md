# Site do Analista Documental Pro

Páginas estáticas em português para hospedar com GitHub Pages.

## Antes de publicar
1. Confirme o nome público do responsável: `J. Luciano`.
2. Em `suporte.html`, substitua `TODO: inserir URL pública...` pelo link real do repositório público e confirme que Issues está habilitado.
3. Em `privacidade.html` e `termos.html`, preencha a data de publicação e revise as declarações para confirmar que refletem a configuração real.
4. Não publique até revisar as políticas e termos. Este pacote não afirma práticas de retenção ou exclusão de dados da plataforma ChatGPT.
5. Não inclua documentos confidenciais, dados pessoais desnecessários ou credenciais no repositório.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `analista-documental-pro-site`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação. O GitHub mostrará o endereço real do site em Settings → Pages.
6. Abra cada página em uma janela anônima para confirmar que funciona sem login.
7. Copie os URLs reais para os campos de site, suporte, política de privacidade e termos no portal de submissão do plugin.

O endereço público do site e os URLs individuais só podem ser confirmados depois de criar e publicar o repositório. Não use links inventados ou URLs de exemplo.
