Suporte

Para relatar um problema ou sugerir uma melhoria no Analista Documental Pro, utilize a área de Issues do repositório público do projeto no GitHub.

Abra a área de Issues do projeto no GitHub para relatar problemas ou sugerir melhorias. Se não conseguir abrir uma solicitação, consulte o repositório público do projeto.

Ao relatar um problema, descreva a função utilizada, o resultado esperado e o resultado observado. Não publique documentos pessoais, contratos, credenciais, dados sigilosos ou informações de terceiros. Prefira exemplos fictícios ou remova dados identificáveis.
